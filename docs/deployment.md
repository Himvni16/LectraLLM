# LectraLLM deployment guide

## Required services

Deploy the following resources with low network latency between them:

1. **Vercel:** Next.js UI, server routes, orchestration, PDF extraction, and local cosine comparison.
2. **Supabase PostgreSQL:** analyses, workflow state, topics, matches, and scores.
3. **Supabase Storage:** private PDF objects.
4. **Cloudinary:** authenticated lecture-video objects.
5. **Gemini Developer API:** transcription, topic extraction, and embeddings.

```text
Browser → Next.js on Vercel → Supabase PostgreSQL
    ├──→ Cloudinary
    ├──→ Supabase Storage
    └──→ Gemini Developer API
```

## Runtime versions

- Node.js 20.19 or newer; Node.js 22 LTS is recommended.
- npm 10 or newer.
- PostgreSQL provided by Supabase.

## Server environment

Configure these only as server-side variables. Never use a `NEXT_PUBLIC_` prefix for secrets.

| Variable | Required | Production value |
| --- | --- | --- |
| `DATABASE_URL` | Yes | Supabase transaction-pooler URL for PrismaPg and the custom migration runner |
| `DIRECT_URL` | Only for direct Prisma CLI operations | Supabase direct/session connection URL |
| `GEMINI_API_KEY` | Yes | Gemini Developer API key |
| `GEMINI_TRANSCRIPTION_MODEL` | No | Video model; default `gemini-3.8-flash` |
| `GEMINI_TOPIC_MODEL` | No | Structured topic model; default `gemini-3.5-flash-lite` |
| `TOPIC_CHUNK_CHARS` | No | Topic chunk size; default `12000` |
| `GEMINI_EMBEDDING_MODEL` | No | Embedding model; default `gemini-embedding-2` |
| `GEMINI_EMBEDDING_DIMENSIONS` | No | Embedding dimensions; default `768` |
| `VIDEO_MAX_SIZE_MB` | No | Video limit in MiB; default `100` |
| `PDF_MAX_SIZE_MB` | No | PDF limit in MiB; default `25` |
| `AI_TRANSCRIPTION_TIMEOUT_SECONDS` | No | Gemini video-operation timeout; default `1800` seconds |
| `CLOUDINARY_CLOUD_NAME` | Yes | Cloudinary product-environment name |
| `CLOUDINARY_API_KEY` | Yes | Cloudinary API key |
| `CLOUDINARY_API_SECRET` | Yes | Cloudinary server secret |
| `CLOUDINARY_UPLOAD_FOLDER` | No | Authenticated video namespace; default `lectrallm/videos` |
| `SUPABASE_URL` | Yes | Supabase project URL for Storage |
| `SUPABASE_SERVICE_ROLE_KEY` | Yes | Server-only Storage/API key |
| `SUPABASE_STORAGE_BUCKET` | Yes | Existing private PDF bucket |

The transaction-pooler PostgreSQL configuration removes conflicting SSL query parameters in memory and passes `ssl: { rejectUnauthorized: false }` directly to `pg`. TLS remains enabled. The application never sets `NODE_TLS_REJECT_UNAUTHORIZED=0`.

## Database setup and migrations

Use a trusted release environment with production variables configured:

```powershell
npm ci
npm run prisma:generate
npx prisma validate
npm run db:migrate:status
npm run db:migrate
```

`db:migrate:status` is read-only. The apply command reads checked-in Prisma migration folders in lexical order, validates raw-file SHA-256 checksums, and maintains Prisma-compatible history. Each migration is serialized with a transaction-scoped advisory lock and migration state is rechecked after the lock is acquired. Unresolved failures, checksum drift, and transaction-incompatible SQL stop application.

Back up production data according to Supabase operational guidance before applying migrations.

## Provider configuration

### Supabase Storage

- Create the bucket named by `SUPABASE_STORAGE_BUCKET`.
- Keep it private.
- Set the file-size limit to 25 MiB or the matching configured limit.
- Allow `application/pdf`.
- Keep the service-role key server-only.

### Cloudinary

- Configure authenticated delivery for lecture videos.
- Keep the API secret server-only.
- Confirm the configured upload limit and account credit allowance.
- Ensure signed upload timestamps are generated by a clock-synchronized server.

### Gemini

- Enable the configured transcription, structured-output, and embedding models.
- Keep the API key server-only.
- Verify quotas with representative lecture videos before launch.

## Long-running analysis behavior

The browser invokes one resumable stage at a time. A ten-minute database lease prevents overlapping polling, refreshes, and platform retries from duplicating provider work. Expired leases are recoverable.

Video transcription is split across upload, single-state checks, and generation. The persisted Gemini file identifier allows later invocations to resume. `PROCESSING` is a normal state and the browser waits before invoking `/run` again.

The application routes use `maxDuration = 300`, the supported Hobby limit in the current setup. A Cloudinary-to-Gemini transfer or transcript generation can still theoretically exceed that limit. Test representative video size and duration before production use.

## Build and deploy

```powershell
npm ci
npm run prisma:generate
npm run typecheck
npm run lint
npm test
npm run build
```

Deploy the repository root as the Vercel project. The browser uploads large media directly to its storage provider; Vercel routes receive only authorization, finalization, and orchestration requests.

## Release checklist

1. Confirm Node.js 20.19+ and npm 10+.
2. Configure all server variables and verify no secret uses `NEXT_PUBLIC_`.
3. Verify the effective `DATABASE_URL` is the Supabase transaction pooler and is not overridden locally.
4. Validate the private Supabase PDF bucket and authenticated Cloudinary video delivery.
5. Generate Prisma Client and run `npx prisma validate`.
6. Inspect `npm run db:migrate:status` before applying pending migrations.
7. Run typecheck, lint, tests, and a production build.
8. Perform a controlled end-to-end analysis with non-sensitive sample files.
9. Confirm logs and browser responses contain no credentials, signed URLs, or raw provider errors.

## Common production issues

- **Database connection fails:** verify transaction-pooler host, port, username, password, and higher-precedence environment files.
- **Certificate-chain error:** confirm the shared `pg` configuration is used and URL SSL parameters are not overriding its explicit TLS object.
- **Cloudinary upload fails:** verify API credentials, signature time, video limit, and account credits.
- **Supabase PDF upload fails:** verify bucket privacy, MIME restrictions, object path, and size limit.
- **Gemini transcription stalls:** inspect the persisted provider file state, quota, selected model, and route duration.
- **Gemini extraction or embedding fails:** verify model availability, dimensionality, quota, and server outbound access.
- **Large uploads reach Vercel:** verify the browser is using provider-signed uploads rather than sending file bytes through a Next.js route.
- **Migration status differs from files:** resolve failed history or checksum drift before applying anything.

## Scope boundary

This deployment supports the existing lecture/PDF comparison workflow. It does not add authentication, multi-tenancy, course administration, OCR, background queues, notifications, or syllabus management.
